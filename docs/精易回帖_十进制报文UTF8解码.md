# 精易帖回复参考

对应帖子：楼主 Python 能解十进制报文，易语言转进制再解码失败。

## 原因（可直接回帖）

不是“进制转换”本身的问题，主要有两点：

1. 报文里有大量字节 `0`。易语言如果先 `到文本()`，会在第一个 `0` 处截断。
2. 包里中文是 **UTF-8**，不是易语言默认的 GBK/ANSI。

Python 能解，是因为全程按 `bytes` 处理，再用 `decode("utf-8", errors="ignore")`，最后过滤控制字符。

正确做法：十进制 → **字节集** → 按 UTF-8 扫描拼文本（非法字节跳过）。

完整可粘贴子程序见：`docs/易语言_十进制报文UTF8解码.txt`
