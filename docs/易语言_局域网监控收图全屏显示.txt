' ============================================================
' 保存体积优化：8MB/张 → 通常压到几百 KB
'
' 【原因】
' 8,642,560 字节很像未压缩 BMP。若直接：
'   写到文件 (“...\1.jpg”, 收图缓冲)
' 只是把 BMP 写成了 .jpg 后缀，体积几乎不变。
'
' 【办法】
' A. 治本：发送端改成发 JPEG（质量 50~70）
' B. 接收端：保存前用 GDI+ 转成真正 JPEG（下面代码）
'
' 创建完毕增加：
' 保存JPEG质量 ＝ 60    ' 1~100，越小越省空间
' ============================================================
