' 局域网监控收图（防闪退稳定版）
'
' 【闪退原因】
' 上一版用 载入图片 得到的句柄直接 SelectObject / StretchBlt / DeleteObject，
' 在多数易语言环境里该句柄不是可安全选入 DC 的 HBITMAP，运行即崩溃。
'
' 【全屏正确做法】
' 1. 设计器选中「画板_显示屏幕信息」
' 2. 属性「底图方式」从「左上」改成「拉伸」  ← 你截图里正是左上，所以不铺满
' 3. 收完整帧后只赋：画板.底图 ＝ 帧数据
' 不要再走 GDI StretchBlt。
'
' 【用法】
' 1. 声明下面「程序集变量」
' 2. 粘贴子程序，替换原 _服务器_局域网监控系统_数据到达
' 3. 画板底图方式＝拉伸；启动时 是否接收＝真
' 4. DLL 只需 RtlMoveMemory（解析 BMP 长度用）；若只收 JPEG 可删掉 BMP 段和该 DLL
' ============================================================
