' ============================================================
' 局域网监控：收图拼包 + 画板全屏显示（优化版）
'
' 【你原来不铺满的原因】
' 1. 只写了 画板.底图＝收图缓冲，底图按「原图像素」贴在左上角，
'    不会自动拉满画板。你虽声明了 显示宽度/比例/边距，但从未使用。
' 2. 收图缓冲、上次刷新时间 若是「局部变量」，每次数据到达都会清空，
'    半包拼不稳；完整帧偶发能出来，但残缺 JPEG 可能只解出上半截，
'    看起来就像「不是全屏图」。
'
' 【用法】
' 1. 粘贴本文件 DLL命令 + 子程序
' 2. 用 _服务器_局域网监控系统_数据到达 替换你原来的事件子程序
' 3. 把「画板_显示屏幕信息」的「重画」事件绑到：_画板_显示屏幕信息_重画
' 4. 组件名默认：画板_显示屏幕信息、服务器_局域网监控系统
' 5. 启动监控时：是否接收 ＝ 真
'    全屏铺满方式 ＝ 1   ' 1拉伸铺满；0等比居中
' 6. 程序集变量名不要再当参数名：监控收图_取出完整帧 不要加参数「收图缓冲」
' 7. 不要用取图片宽度/取图片高度（缺支持库会报错37），用 GetObject 版取尺寸
' ============================================================
