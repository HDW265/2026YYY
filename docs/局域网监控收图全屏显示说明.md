## 运行为什么会闪退

上一版用了：

`载入图片` → `SelectObject` / `StretchBlt` / `DeleteObject`

在很多易语言工程里，`载入图片` 返回的不是能安全选进 DC 的位图句柄，一跑 GDI 就进程崩溃（表现为闪退）。

**稳定版已去掉全部 StretchBlt / GetObject / 载入图片 显示路径。**

## 全屏怎么做（两步）

1. **设计器**：选中 `画板_显示屏幕信息`，把属性 **「底图方式」从「左上」改成「拉伸」**  
   （你之前截图里就是「左上」，所以图只在左上角、看起来不像全屏。）
2. **代码**：收齐完整帧后只写  
   `画板_显示屏幕信息.底图 ＝ 帧数据`

## 还要保留的优化

- `收图缓冲` 等用**程序集变量**（局部变量会每包清空）
- JPEG 用 `FFD8…FFD9` 定帧，避免半包残图
- 不要给 `监控收图_取出完整帧` 加同名参数 `收图缓冲`

## 若画板没有「拉伸」

改用 **图片框**：显示方式＝拉伸图片，赋值  
`图片框_显示屏幕信息.图片 ＝ 帧数据`
