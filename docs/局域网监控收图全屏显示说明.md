# 保存体积优化（8MB/张）

## 原因

约 `8,642,560` 字节/张，基本是**未压缩 BMP**。  
若代码是 `写到文件 (...\1.jpg, 收图缓冲)`，只是把 BMP 写成了 `.jpg` 后缀，**体积不会变小**。

## 怎么办

1. **治本**：发送端改发 JPEG（质量 50~70），网传和落盘都小。
2. **接收端**：保存前用 GDI+ 转成真正 JPEG（见 `易语言_局域网监控收图全屏显示.txt`）。
3. **再省**：加大 `保存间隔毫秒`；`保存JPEG质量` 用 `50~60`。

## 关键改法

把：

```text
写到文件 (保存路径, 收图缓冲)
```

改成：

```text
监控收图_压缩保存JPEG (收图缓冲, 保存路径, 保存JPEG质量)
```

创建完毕：`保存JPEG质量 ＝ 60`
