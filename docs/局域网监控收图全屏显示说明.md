# 你这份代码：删什么、留什么

## 先做设计器（比改代码更重要）

选中 `画板_显示屏幕信息` → 属性 **底图方式**：

- 现在：`图片居左上` ← 所以不铺满  
- 改成：**拉伸**（下拉里选带“拉伸”的那项）

## 必须整段删除（闪退源头）

删掉这 3 个子程序（一个不留）：

1. `监控收图_画板全屏显示`
2. `监控收图_取位图尺寸`
3. `_画板_显示屏幕信息_重画`（若事件里绑了，解绑或留空）

`[Dll命令定义表]` 里若只为 StretchBlt 加过这些，也可删：

- `GetDC` / `ReleaseDC` / `CreateCompatibleDC` / `DeleteDC`
- `SelectObject` / `DeleteObject` / `SetStretchBltMode` / `StretchBlt` / `PatBlt` / `GetObject`
- 数据类型 `监控收图_位图结构`

**只保留** `RtlMoveMemory_整数`（解析 BMP 用；纯 JPEG 也可留着无妨）。

## `数据到达` 里删这些行

删掉（会闪退）：

```text
图句柄 ＝ 载入图片 (帧数据)
...
监控收图_画板全屏显示 (...)
DeleteObject (图句柄)
屏幕图片 ＝ 0
全屏铺满方式 相关判断
```

改成只剩：

```text
最近一帧 ＝ 帧数据
画板_显示屏幕信息.底图 ＝ 帧数据
```

## 程序集变量

可删：`全屏铺满方式`  
可留：`收图缓冲`、`上次刷新时间`、`最近一帧`、`是否接收` 等

## 你代码里还有个拼包 bug（必改）

`监控收图_取出完整帧` 里取完剩余后又写了：

```text
收图缓冲 ＝ 取字节集右边 (...)
收图缓冲 ＝ {  }          ← 这行会把下一帧开头清掉，删掉它
```

只保留「有剩余则取右边，否则清空」二选一，不要取完右边再强制清空。
