# 画板没有「拉伸」时怎么铺满

## 1. 为什么属性里没有拉伸

你的 `画板` 底图方式只有：

- `0. 图片居左上`
- `1. 图片平铺`
- `2. 图片居中`

**画板本身就不支持拉伸底图**，所以改属性无法铺满。  
不要再设 `底图方式 ＝ 2` 指望全屏（那只是居中）。

## 2. `画板_显示屏幕信息.底图 ＝ 帧数据` 改哪里

在子程序 **`_服务器_局域网监控系统_数据到达`** 里，  
已经得到 `帧数据`、通过降频判断之后，**删掉** `载入图片` / `监控收图_画板全屏显示` / `DeleteObject`，换成赋值。

位置示意：

```text
帧数据 ＝ 监控收图_取出完整帧 ()
.如果真 (取字节集长度 (帧数据) ＜ 1)
    返回 ()
.如果真结束

.如果真 (取启动时间 () － 上次刷新时间 ＜ 120)
    返回 ()
.如果真结束
上次刷新时间 ＝ 取启动时间 ()
最近一帧 ＝ 帧数据

' ★ 就写在这里（二选一）
图片框_显示屏幕信息.图片 ＝ 帧数据      ' 推荐，能铺满
' 画板_显示屏幕信息.底图 ＝ 帧数据     ' 仅更新图，不能拉伸
```

## 3. 要铺满：加图片框（推荐）

1. 工具箱拖一个 **图片框**，名称：`图片框_显示屏幕信息`
2. 大小盖住原来的画板区域
3. 属性 **显示方式** 选 **拉伸图片**（名称以你 IDE 下拉为准）
4. 数据到达里用：`图片框_显示屏幕信息.图片 ＝ 帧数据`
5. 画板可隐藏，或先叠在下面不用管

## 4. 仍用画板时

只能左上/平铺/居中显示原图像素，**不能靠底图方式铺满**；可继续用左移/上移挪图。  
不要再用会闪退的 StretchBlt 那套。
